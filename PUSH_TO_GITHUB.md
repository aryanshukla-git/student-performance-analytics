# Steps for you to finish (GitHub + Google Form)

1. Create a new **public** repository on github.com named `student-performance-analytics` (do not add a README there).
2. Unzip this project, open a terminal in the folder, then run:

```bash
git remote add origin https://github.com/<your-username>/student-performance-analytics.git
git push -u origin main
```
(If the folder has no `.git`, run `git init`, `git add .`, `git commit -m "Student Performance Analytics System"`, `git branch -M main` first.)

3. Open the repository in the browser and confirm you can see: main.py, functions.py, students.csv, README.md, Project_Documentation.md, screenshots/.
4. Paste the repository URL into the "GitHub Repository" section of `Project_Documentation.md`, then:

```bash
git add . && git commit -m "Add repository link" && git push
```
5. Paste the same URL into the EWB Google Form.
